How the Data Structures Work

Trie

Trie is used for efficient prefix-based searching. Each character is stored as a node, allowing the system to quickly find products beginning with a particular prefix.

Segment Tree

Segment Tree is used for efficient range queries and updates. It allows the system to calculate total sales for a range of products without scanning every element.

Complexity

Trie insertion: O(L)
Trie prefix search: O(P + K)
Segment Tree range query: O(log n)
Segment Tree update: O(log n)

L = length of the word, P = length of the prefix, K = number of matching results. These costs make trie and segment tree suitable for instant search and efficient range calculations.
